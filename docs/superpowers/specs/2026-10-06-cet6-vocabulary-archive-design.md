# 六级词汇档案设计

## 目标

把单词本从收藏列表升级为可筛选、可标记掌握度、可展开精读的六级词汇档案。

## 词条内容

- 摘要层：单词、音标、词性、语境义、最高频义、短语、原文例句、来源次数和重要度。
- 展开档案：词根/构词提示、派生词、同义词、反义词、易混词及区别、额外例句、全部来源文章。
- 每条词保存 `learningStatus`：`unknown`、`fuzzy`、`known`，默认 `unknown`；状态筛选可与搜索/来源筛选叠加。
- 对缺少扩展字段的旧词条提供“补全六级档案”按钮，才发起一次 DeepSeek 单词请求；结果写回本地词条。

## AI 契约

- 单词 API 返回既有释义、短语、例句之外的 `wordFormation`、`synonyms`、`antonyms`、`confusables`、`importanceTags` 和 `extraExamples`。
- 所有内容需贴合 CET-6，避免不必要的生僻词信息或伪造词源。
- 预研读词条允许缺少扩展字段，避免全文预处理过慢。

## 界面

- 单词本顶部提供全部、不会、模糊、认识、高频、易混、学术词快捷筛选。
- 词条卡显示高价值摘要；点击展开档案；状态按钮即时保存。
- 不改动既有来源、Word/Markdown 导出和文章库数据。
