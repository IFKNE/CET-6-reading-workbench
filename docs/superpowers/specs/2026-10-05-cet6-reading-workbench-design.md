# 六级英语精读工作台：设计规格

## 目标

构建一个仅在本机运行的英语六级精读网站。学习者粘贴一篇英文文章后，可逐词查询和收藏；可翻译短语、句子与整段；可将单词本导出为 Markdown 文档。

## 范围

首个版本只服务于使用者自己的电脑。翻译请求由本机服务转发至 DeepSeek API；API Key 存放在本地 `.env` 文件，绝不传给浏览器代码，也不会被提交到源码中。

## 使用流程

1. 学习者打开工作台，粘贴一篇英文文章。
2. 网站保留原有段落，并在阅读页将每个英文单词处理为可点击对象。
3. 学习者可点击单词、拖选短语或句子，或点击段落翻译按钮。
4. 网站向 DeepSeek 请求相应范围的释义或译文，并在批注面板展示结果。
5. 学习者可把有价值的单词加入本地单词本。
6. 学习者可将单词本下载为 Markdown 文件。

## 界面

整体采用“纸质精读批注本”风格：暖白色阅读纸、深色正文、墨绿色功能强调色、柔和荧光笔高亮，以及固定的研读笔记侧栏。界面的优先目标是适合长时间阅读，而不是聊天软件式的界面。

### 主要区域

- **文章输入区**：粘贴文章、载入一小段内置示例、进入精读。
- **阅读区**：按段落显示文章；每个单词可点击；每段有整段翻译按钮。
- **选中文本工具条**：选中非空文本后出现，提供短语或句子翻译。
- **批注面板**：展示选中的原文、中文翻译、词性和收藏单词操作。
- **单词本抽屉**：查看已收藏单词，并导出 Markdown。

## 翻译与释义规则

### 单词查询

点击单词时，服务器要求 DeepSeek 返回结构化 JSON，包括词形还原、音标（可提供时）、结合当前语境的推荐释义，以及按词性分组的义项。

每个义项带有 AI 估计的常见度等级：

- `最高频`：通常是最优先掌握的意思。
- `常见`：出现频率较高，但低于第一义项。
- `较少见`：补充性的其他义项或专业义项。

同一词性下的释义必须从高频到低频排列。该排序是 AI 的常见度判断，不是语料库频次保证；界面会明确标记“常见度判断”，并单独指出当前文章语境中最可能的意思。

### 短语、句子与段落翻译

前端把原文和请求类型（`短语`、`句子`、`段落`）发送至服务器。DeepSeek 返回简洁、自然的中文译文。段落翻译保留原有段落边界。翻译结果不会被自动加入单词本。

## 数据与本地保存

文章内容、当前批注和单词本都保存在浏览器本地存储中。每条单词本记录包含：

- 单词与词形还原结果；
- 已选择的中文释义及词性；
- 原句或上下文；
- 收藏日期。

导出 Markdown 时，网站生成一个可下载的 `.md` 文件，文件包含标题、导出日期和逐个单词条目及其上下文。

## 本地架构

项目由浏览器界面和一个轻量的本机 Node 服务组成：

```
浏览器界面 -> POST /api/translate -> 本机 Node 服务 -> DeepSeek API
```

服务端接收明确的任务类型，校验文本长度和参数，选择相应提示词，调用 DeepSeek 的 OpenAI 兼容接口，校验返回内容后向浏览器返回安全的 JSON。浏览器不会直接调用 DeepSeek。

## 异常处理

- 未配置 `DEEPSEEK_API_KEY` 时，展示配置指引，不发送请求。
- 网络或 API 出错时，展示可重试的批注错误信息；文章和单词本不受影响。
- 参数不合法或文本超长时，在本地给出明确提示。
- 单词结构化结果无法解析时，服务端会尝试一次修复请求；仍失败则返回易理解的错误说明。

## 验证方式

- 验证单词、短语、句子和段落请求都使用正确的提示词，并在页面显示结果。
- 验证单词可收藏、刷新后仍存在、可删除，并能导出合法的 Markdown 文档。
- 验证 API 请求只从本机服务发出，且 `.env` 不会进入源码管理。
- 验证缺少 Key 和模拟 API 报错时，页面提供清晰的恢复说明。

## 首版暂不包含

首版不包含账户系统、云端同步、间隔复习、自动语法讲解、PDF/OCR 导入、多用户协作或公开部署。
