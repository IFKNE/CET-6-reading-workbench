# 阅读书房视觉改版设计

## 目标

将六级精读工作台改造成更像专业阅读器的“阅读书房”：模块层级清楚，支持浅色/暗色模式，精读文章以纸质书页呈现，同时保持现有文章库、单词本与 AI 精读功能。

## 主题

- 默认浅色主题保留暖纸、墨绿和金色标记，降低无关装饰的对比度。
- 暗色主题使用深墨绿/炭黑作为应用背景，正文纸页保持低亮度暖灰色，避免纯黑底与高亮白字造成视觉疲劳。
- 用户的主题选择写入 `localStorage`，下次打开自动恢复；系统主题不覆盖用户手动选择。
- 顶部提供带文字的主题切换按钮，图标和 `aria-label` 反映当前可执行操作。

## 信息架构

- 顶部导航分为：开始精读、我的精读、单词本、主题切换。
- “开始精读”返回粘贴区；“我的精读”平滑定位至文章书架；“单词本”维持现有抽屉。
- 输入区、文章书架、阅读区和词汇区各有小标题和独立卡片边界，视觉上不再混为连续长页。

## 精读文章页

- 阅读区加入文章标题、分类书签、预研读状态和阅读进度位置。
- 英文原文放进中央书页容器：上部显示章节信息，正文有内边距、页码和轻微书脊/纸张阴影。
- 大屏下保持原文书页与右侧批注卡的双栏布局；移动端自动切为单栏，批注在文章之后。
- 重点词位于书页后，使用低密度索引卡，不抢正文注意力。

## 文章库和单词本

- 文章库卡片采用书脊感边框与分类书签；标题、更新时间、重点词数量为三级文字层级。
- 单词本抽屉在两套主题均使用独立浮层颜色，来源文章、词频和导出按钮维持可读对比度。

## 实现边界

- 只调整 HTML 语义结构、CSS 自定义变量与前端主题状态；不改变 IndexedDB 数据格式、翻译 API 或 DOCX 导出接口。
- 无图片、无第三方 UI 框架；保留当前响应式断点并补充主题切换测试。

## 验收

- 浅色与暗色主题均能清楚阅读正文、批注、文章库和单词本。
- 主题选择刷新后保持。
- 导航可以到达开始精读、文章书架和单词本。
- 阅读页面在宽屏呈现书页/批注双栏，在窄屏变为单栏且所有操作可用。
